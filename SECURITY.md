# Security scope

This repository is a research/reference profile, not a production authorization or safety system.

Please report issues that cause:

- evidence for one proposition/source/view to authorize another;
- unvalidated protocol metadata to reach the premise gate;
- silent loss of semantics at a supported normalization boundary; or
- secrets to be retained in published evidence artifacts.

Do not report the documented absence of cryptographic source authentication, freshness, or TOCTOU closure as implementation vulnerabilities; those are explicit non-goals for this release.
